# how to download voices for tts (piper)

1. go to [this website](https://huggingface.co/rhasspy/piper-voices/tree/main)
2. get the right voice (if you want to know which one is which visit [this website](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes))

in the **tts_models.json** file, there are a few links and directories to following languages: 
* ro
* ru
* en
* de
* fr

these are only the languages that i know, maybe in future the list is going to expand itself, but ill keep it that way till then
