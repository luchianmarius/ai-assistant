# how to download voices for tts (piper)

1. go to [hugging face](https://huggingface.co/rhasspy/piper-voices/tree/main)
2. get the right voice (if you want to know which one is which visit [this documentation](https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes))

in the **[tts_models.json](https://github.com/luchianmarius/ai-assistant/blob/main/audio/tts/tts_models.json)** file, there are a few links and directories to following languages: 
* ro
* ru
* en
* de
* fr

these are only the languages I know, I'll maybe update and expand the list in the future, but I'll keep it that way till then
